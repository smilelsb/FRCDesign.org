## 概览

阶段 0 是整个学习课程的基础，将向学生介绍 CAD（计算机辅助设计），尤其是贯穿本课程使用的云端 CAD 平台 Onshape。本阶段确保所有学生在开始实际的机构设计之前，都已具备必要的工具和知识，并完成账户设置。

这些入门阶段与后续阶段同样重要。强烈建议所有学生学习本小节，以确保他们拥有完成其余课程所需的全部工具。

## 为什么使用 CAD？

CAD 在 FRC 中至关重要，主要有以下几个原因：

1. **设计迭代**：队伍可以在制造前快速测试和修改设计
2. **团队协作**：多名队员可以清晰地查看和理解设计
3. **制造规划**：CAD 可以作为制造蓝图，为制造工作提供帮助
4. **教学工具**：帮助新队员理解机器人机构和装配方式
5. **重量管理**：让队伍能够在整个设计过程中跟踪机器人重量

## 账户设置

本阶段将逐步讲解几项关键的设置步骤：

1. 创建 Onshape 教育版账户
2. 安装必要的 FeatureScript（自定义特征脚本）：
   - Electronics Mounting（电子元件安装）
   - Extrude Individual（单独拉伸）
   - Gusset Generator（加强板生成器）
   - Shaft Generator（轴生成器）
   - Tube Converter（管材转换器）
   - Belt & Chain Generator（同步带与链条生成器）
3. 设置 FRCDesignApp（FRC 零件库）

## CAD 理论

阶段 0 将介绍基础 CAD 概念：

1. **Sketch（草图）**：构成三维模型基础的二维图形
2. **特征**：创建或修改三维几何体的操作
3. **Part Studio（零件工作室）与 Assembly（装配体）**：
   - 零件工作室：设计单个零件的工作区
   - 装配体：组合并约束零件的工作区

## 界面导航

学生将学习如何使用 Onshape 界面：

1. **文档管理**：
   - 创建新文档
   - 使用文件夹组织文档
   - 版本控制
2. **界面元素**：
   - 工具栏
   - 特征列表
   - 图形区域
3. **视图控制**：
   - 平移、缩放和旋转
   - 标准视图
   - 视图快捷键

## 最佳实践

本阶段强调以下几项最佳实践：

1. **组织方式**：
   - 合理命名
   - 文件夹结构
   - 特征组织
2. **文件管理**：
   - 版本控制
   - 正确共享文档

## 学习成果

完成阶段 0 后，学生应当能够：

1. 拥有一个可以正常使用的 Onshape 账户，并安装必要工具
2. 理解基础 CAD 概念和术语
3. 熟练使用 Onshape 界面
4. 掌握创建基础草图和特征的方法
5. 理解合理的组织方式和最佳实践
6. 为阶段 1 的动手练习做好准备

## 后续学习

阶段 0 通过以下方式帮助学生为后续阶段打好基础：

1. 奠定扎实的理论基础
2. 确保正确设置工具
3. 养成良好的组织习惯
4. 循序渐进地介绍关键概念
5. 为更复杂的设计做好准备

本阶段强调花时间正确理解基础知识并妥善设置工具，因为这些投入会在后续设计更复杂的机构时带来长期回报。本阶段既适合毫无基础的初学者，也能为更有经验的 CAD 用户提供实用的设置信息。

如果时间充裕，我们鼓励大家学习链接中提供的 Onshape 学习课程。与其让学生之后自行摸索这些工具的用法，不如现在就深入了解 Onshape 文档的工作方式，这样可以节省后续时间。
