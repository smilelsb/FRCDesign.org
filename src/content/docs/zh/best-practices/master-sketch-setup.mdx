---
title: 布局草图最佳实践
description: 创建主布局草图时应遵循的最佳实践。
---


主布局草图由一系列草图组成，用于确定各机构的主要尺寸、与场地元素的交互关系以及机器人的尺寸限制。随后，将主布局草图插入各机构的 Part Studio（零件工作室），再以导入的布局草图为依据对各个零部件进行建模。这样可以更轻松地采用自顶向下设计方法整合各机构。

| **始终包含**                                                                | **有时包含**                                        | **绝不包含**                                                 |
|:----------------------------------------------------------------------------|:----------------------------------------------------|:------------------------------------------------------------|
| 底盘尺寸                                                                    | 齿轮                                                | 板件形状等具体细节                                           |
| 根据原型测试确定的末端执行器轮组位置                                        | 同步带                                              | 加强板                                                      |
| 场地元素和伸展限制                                                          | 链条                                                | 安装孔                                                      |
| 机构运动路径                                                                | 电机位置                                            |                                                             |
| 比赛物路径                                                                  |                                                     |                                                             |

这并不是一份详尽的清单；不同队伍、不同机器人架构的具体内容可能有所不同。如有需要，后续可以轻松增减细节。

所有决定机器人几何形状的重要尺寸都集中在布局草图零件工作室中，因此可以统一查看和修改。否则，就必须逐一进入各个子系统修改几何形状，再尝试让它们在机器人的顶层装配体中相互适配。

绘制主布局草图时，应始终先画出传动底盘、保险杠、初始构型和伸展限制，接着再绘制场地元素。可以让机构与保险杠进行硬对齐，以确保其几何结构无需复杂的软件控制或机械设计就能完成得分。

<Aside type="tip" title="Tip（提示）">
赛季启动后，可以立即创建一个零件工作室，在其中绘制传动底盘、伸展限制和场地元素的布局草图。然后复制该零件工作室，用它测试多种机器人架构的几何方案，再从中做出选择。
</Aside>

机器人的设计应专门针对与场地元素和比赛物的交互。对于主布局草图，这意味着每个子系统的每一处尺寸都应有明确依据，无论这个依据来自场地元素、伸展限制，还是各子系统之间的相互关系。

<Aside type="example" title="Example（示例）">
升降机构的长度应由其所移动执行机构的起点和终点位置决定，因为这些位置取决于执行机构与场地元素的交互方式。
</Aside>

<Aside type="tip" title="Tip（提示）">
可以绘制表示旋转子系统运动范围的构造圆，并标注另一个子系统与该圆之间的距离，以确保两者之间留有间隙。
</Aside>

要高效绘制布局草图，必须保持良好的组织结构。这意味着：

- 在主布局草图零件工作室中建立多个草图，通常每个子系统对应一个草图。务必将它们彼此分开！
- 为各草图起对应的名称
- 还可以为草图设置[不同的颜色](https://www.youtube.com/watch?v=ZG_gVeGdI5c)，以便区分
- 绘制每个运动子系统所有可能的状态
