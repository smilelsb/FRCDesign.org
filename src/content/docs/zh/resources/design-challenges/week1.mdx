import { Tabs, TabItem } from '@astrojs/starlight/components';

欢迎参加第一项设计挑战！我们将从机器人最基础的舵轮底盘开始。挑战分为初级和高级两个难度。建议先完成初级挑战，再继续完成高级挑战。高级挑战的内容与初级挑战相同，但增加了几项额外要求。

<Tabs>
  <TabItem label="初级挑战">
    * 选择一款 COTS（现成商业零件）舵轮模块
    * 使用 2" x 1" 铝方管组装底盘
    * 添加底盘电气底板
    * 底盘必须符合上场比赛的规则要求。
  </TabItem>
  <TabItem label="高级挑战">
    * 规划并添加所有电气元件的安装孔，同时确保为线缆留出空间
    * 添加电气元件模型，并将所有零件配合到一起
    * 添加电池并用合适的方式将其固定
    * 添加保险杠
    * 添加保险杠安装结构
  </TabItem>
</Tabs>

<Aside type="note" title="需要帮助？">
如果遇到困难或有任何问题，欢迎在 Discord 服务器中提问！也可以把你的设计发出来请大家帮忙检查！
</Aside>

如果需要一些设计灵感，可以在[这里](/mechanism-examples/drivebase/swerve/)查看底盘示例。
