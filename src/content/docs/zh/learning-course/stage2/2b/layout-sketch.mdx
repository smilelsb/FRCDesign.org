## 布局草图

由于使用 MAXPlanetary 行星齿轮箱进行减速传动，这个布局草图非常简单。

1. 使用 Origin Cube FeatureScript（自定义特征脚本）插入 Origin Cube
2. 标注横梁尺寸
3. 在横梁上方布置转轴位置和主动链轮位置。在两者之间绘制一条构造线并标注尺寸，使链条具有足够长度来使用直列式张紧器。
4. 创建构造圆，表示两个链轮的分度圆和电机直径。
