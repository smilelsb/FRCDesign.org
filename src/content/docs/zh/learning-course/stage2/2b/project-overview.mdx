## 项目概览

你将设计一个简单的死轴转轴机构。虽然这个机械臂并非针对某一特定比赛设计，但它会帮助你学习适用于各种旋转机构的核心概念。

项目要求如下：

- **齿轮箱：** 使用 MAXPlanetary 行星齿轮箱。
- **链条：** 使用 #25 链条和大链轮进行减速传动。
- **轴：** 使用 7/8 英寸管材作为死轴，并确保其得到适当支撑。
