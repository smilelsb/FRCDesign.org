## Part Studio（零件工作室）

1. 在主布局草图的转轴点上创建一个归属于 Origin Cube 的配合连接器。它将在顶层装配体中用于定义子装配体之间的运动。
2. 创建横梁方管
3. 创建转轴支撑板
4. 使用 FeatureScript 创建链条和六角轴
5. 创建死轴管材、隔套和垫圈。
6. 创建机械臂所用的方管，包括螺栓操作孔。
7. 创建一块板件，使链轮与机械臂之间保持间距。
8. 为所有零件命名，并指定材料和外观
