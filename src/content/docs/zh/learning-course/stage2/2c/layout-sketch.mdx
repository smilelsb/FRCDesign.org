## 布局草图

1. 使用 Origin Cube FeatureScript（自定义特征脚本）插入 Origin Cube
2. 绘制底盘侧面和保险杠轮廓
3. 绘制球越过保险杠的路径
4. 绘制使比赛物体沿该路径运动所需的滚轮或轮子位置。使用 1B 中学到的同步带传动工具标注滚轮位置尺寸。将中心距缩短 0.02" 有助于简化装配并提高滚轮效率。
5. 使用草图圆周阵列表示拾取滚轮收起时的位置，并确定转轴的位置
