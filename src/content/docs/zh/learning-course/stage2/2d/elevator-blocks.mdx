## 升降滑块

现代升降机构都会使用某种形式的“升降滑块”，通过轴承让各级段能够相互平稳滑动。

### COTS 升降滑块

考虑到一般队伍需要投入的时间和加工能力，大多数队伍会从 WCP 或 TTB 购买升降滑块，而不是自行加工。不过，升降滑块也可以用板件而非整块坯料制作（参见 [2471 队 2018 年机器人 CAD](https://cad.onshape.com/documents/bd18a956391f75b5bca27546/w/827793489fb93072e2a1d993/e/adea515b9f2a94ccfd7ca72e)）。

### 参考设计

参考设计使用 WCP Inline Clamping 和 Inline 滑块，但也可以替换为 WCP 或 TTB 的其他滑块；除了调整侧面各级段之间的距离外，通常几乎不需要修改设计。
