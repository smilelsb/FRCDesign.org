## 总结

你已经完成了阶段 2D！下面总结一下你在这一阶段学到的内容：

- 级联绕绳升降机构的概念和关键组件
- 升降机构主布局草图的概念与几何
- 装配体中的线性关系
- 管塞和防压块在方管装配中的用途
- 继续练习使用 Origin Cube 建模带运动部件的机构

在这种升降机构上安装其他机构时有很大的设计自由度。如果将它相对机器人正面旋转 90 度安装，甚至可以创建一个能够上下移动的穿透式机构。

在下一阶段继续练习主布局草图集成后，你将能够在阶段 3 后续部分复现一台带倾斜升降机构的机器人。
