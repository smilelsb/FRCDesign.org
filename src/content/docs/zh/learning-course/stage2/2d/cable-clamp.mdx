## 绳索夹板

级联升降机构通过将固定长度的绳索从夹板一侧移动到另一侧，推动升降机构上升。绳索夹板通常用螺栓安装在某种横梁上。

<ContentFigure src="../img/2d/cable-clamp.webp" alt="TTB 绳索夹板" width="50%"/>

### 参考设计

参考设计使用 TTB 绳索夹板，以保持绕绳组件一致（这些组件以[套件](https://www.thethriftybot.com/products/elevator-dyneema-pulley-kit)形式提供）。夹板由两块板件组成：第一块紧固到方管上，第二块**仅**紧固到第一块板上。你可以选择为螺栓开设操作孔，也可以配合防压块，让螺栓完全穿过横梁。

<Aside type="note" title="Note（备注）">
WCP 绳索夹板采用类似设计，但紧固件会穿过两块板并进入横梁方管，使横梁共同承受夹紧力。
</Aside>
