## 项目概览

升降机构本质上是用于移动其他机构的机构，因此本项目与死轴转轴机构类似，不会提供太多具体比赛背景，而是重点学习设计流程和组件。在阶段 3 中，你会练习结合机器人整体环境设计升降机构。
