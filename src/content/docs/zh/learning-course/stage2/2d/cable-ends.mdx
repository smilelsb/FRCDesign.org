## 绳索端部

绳索端部可以说是升降机构绕绳系统中最需要正确处理的部分。如果处理不当，绕绳系统可能会在碰撞中散开；这通常会让升降机构以及所有依赖它运动的机构在整场比赛中完全失效。级联绕绳系统中，每个级段至少有一个绳索环路，用于驱动下一级段运动。

### 绳索张紧

为了确保运动顺畅，这些绳索需要张紧。使用棘轮绳筒是张紧绳索的最佳方法之一。COTS 方案是使用 [WCP 棘轮板](https://wcproducts.com/products/wcp-0585)，并让六角轴充当绳筒；也可以切下棘轮扳手的端部并将其固定到机构上，制作简单的自制方案。在六角轴上钻孔，迫使绳索绕在轴上。

务必在绳索上打一个能够自行收紧的绳结，防止其在高载荷下松脱。只需要在一侧使用棘轮绳筒，另一侧使用简单的固定环即可。为了正确张紧，需要在施加张力前松开夹板。这样做有两个原因：一是保持各级段同步，二是让张力施加到两侧，而不只是带棘轮的一侧。
