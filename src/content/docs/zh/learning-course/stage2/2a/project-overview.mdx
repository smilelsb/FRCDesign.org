## 项目概览

你将设计一个飞轮发射机构，用于发射 2020/2021 Infinite Recharge 比赛中的 Power Cell：一种直径 7 英寸的泡沫球。观看 [2020 比赛动画](https://www.youtube.com/watch?v=gmiYWTmFRVE)、[1690 队 2020 机器人发布视频](https://www.youtube.com/watch?v=7EPv0gfnSEw) 和 [2021 Chezy Champs 决赛第 2 场](https://www.youtube.com/watch?v=kBWlbf5j5SI)，可以帮助你理解比赛任务。场地元素可参考 [比赛手册](https://firstfrc.blob.core.windows.net/frc2020/Manual/2020FRCGameSeasonManual.pdf) 和 [场地布局图](https://firstfrc.blob.core.windows.net/frc2020/PlayingField/LayoutandMarkingDiagram.pdf)，Power Cell 规格可参考 [AndyMark 网站](https://www.andymark.com/products/7-in-diameter-foam-ball)。

这个发射机构将被设计为从白色 “Initiation Line” 后方，将 Power Cell 发射进高目标。
