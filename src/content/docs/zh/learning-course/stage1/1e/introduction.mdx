## 介绍

在前面的部分中，你已经学习了零件建模和动力传动的基础，也学习了自顶向下设计工作流程。
在阶段 1E 中，你将通过**向阶段 1D 中开始建模的底盘添加其余必要组件**，继续练习这些建模技巧。
这会帮助你在保持内容相对简单的同时，熟悉建模完整子系统的典型工作流程。

### 子系统工作流程
建模一个子系统时，典型工作流程包括：

1. 在布局草图零件工作室中创建布局草图
2. 将布局草图派生到零件工作室中
3. 基于布局草图创建机构的基础结构（板件、管材等）
4. 将基础结构插入装配体，进行组配合，紧固到原点，并完成结构创建
5. 将该装配体插入机器人顶层装配体
6. 回过头添加不同组件，完成子系统细节
