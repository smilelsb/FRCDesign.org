## 项目概览

到目前为止，你已经完成了主布局草图，并建模了框架和基础底板。

<ContentFigure src="../img/1d/drivetrain-assembly.webp" alt="阶段 1D 舵轮底盘" width="60%">阶段 1D 舵轮底盘</ContentFigure>

**为了完成底盘，你将根据后续页面内容添加以下细节：**

1. **电池安装：** 每台机器人都需要电池。虽然电池位置会根据机器人上的其他机构而变化，但它应始终尽可能放低，以提高机器人稳定性。

2. **电子元件安装：** 机器人上必须预留足够空间，方便布线。通常，机器人的电子元件会安装在底板上。

3. **底板减重开槽：** 这一步是可选的。有些队伍会选择在底板上添加开孔，以减轻重量并让布线更方便。不过，对底板进行减重开槽可能会显著增加加工时间。

4. **保险杠和保险杠安装：** 虽然保险杠规则每年可能不同，但几乎总是要求安装保险杠，用于保护你的机器人和其他机器人免受碰撞影响。让保险杠易于安装和拆卸，也能在比赛现场显著提升使用体验。

<Aside type="note" title="Note（备注）">
尽管前三个细节不会直接引用布局草图，但它们会引用那些引用了布局草图的零件（框架），因此如果发生修改，它们也会相应更新。
</Aside>

这些细节的具体实现会根据机器人其他部分以及不同队伍的习惯而变化，但这里提供了一个阶段 1E 的示例参考。
