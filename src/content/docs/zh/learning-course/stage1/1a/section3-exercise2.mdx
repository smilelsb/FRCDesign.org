## 练习 2：Swerve（舵轮）底盘装配

掌握基础铆钉操作后，接下来在Swerve（舵轮）底盘上安装铆钉。

开始前，在你复制的模板文档里，打开 “Section 3” 文件夹中的 “S3 Exercise 2” 零件工作室。

**按下面视频完成本练习。**

<ContentFigure src="UZHMD1GFG44">Swerve（舵轮）底盘装配</ContentFigure>

<Aside type="tip" title="Tip（提示）">
本练习会用到 `Replicate`（仿制）工具，便于把铆钉、螺栓、轴承等相同且重复的零件快速复制到尺寸相同的一组孔位上。
</Aside>

1. 复制、粘贴并把剩余的加强板通过紧固配合安装到底盘框架上。
2. 从 FRCDesignLib 插入铆钉，用 **Replicate**（仿制）工具把它们紧固到加强板上。
3. 插入 **MK4i** Swerve（舵轮）驱动模块（配置保持默认即可，不用改）。
4. 把模块通过紧固配合安装到框架上。**暂时不需要添加螺栓。**

<Aside type="tip" title="Tip（提示）">
可尝试用装配体的“圆形阵列”工具，把一个Swerve（舵轮）模块复制到整个底盘的其余安装位。
</Aside>

加强板、铆钉和Swerve（舵轮）模块都装好后，进入下一个练习。
