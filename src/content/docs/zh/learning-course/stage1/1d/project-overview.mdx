## 项目概览

在本阶段，你将设计一个 Swerve（舵轮）底盘。底盘是机器人可移动的平台，其他所有机构都会围绕它进行设计并安装在它上面。随着可靠的 COTS（现成商业零件）舵轮模块出现，设计舵轮底盘已经变得容易得多，并且舵轮底盘已成为 FRC 中最常用的竞赛底盘形式。

舵轮底盘由四个*Swerve 模块*组成。每个模块有两个电机：一个用于驱动车轮旋转，另一个用于控制转向。这让机器人可以在任意方向平移，而不受机器人自身旋转方向限制。在本项目中，我们会使用 [SDS MK4i 模块](https://www.swervedrivespecialties.com/products/mk4i-swerve-module)。市面上还有许多其他 COTS 选项，它们各有优势和取舍。

### 底盘框架

如阶段 1A 中介绍的那样，机器人结构通常由铝制方管构成，底盘也不例外。大多数队伍会选择在方管上设计标准 0.5" 间距、0.196" 直径的孔阵列。这样可以实现模块化，并方便集成许多 COTS 零部件，例如加强板。

方管型材可以从大多数金属供应商处购买，但许多 FRC 供应商，包括 [WCP](https://wcproducts.com/collections/systems-structure/products/punched-tubing)、[TTB](https://www.thethriftybot.com/products/thrifty-box-extrusion) 和 [REV](https://www.revrobotics.com/MAXTube/)，也销售预加工孔阵列的方管，这可以显著减少加工时间和设备需求。
