## 介绍

到目前为止，你已经通过课程和 FRC 相关练习学习了 CAD（计算机辅助设计）基础，但还没有在更完整的项目语境中进行设计。在本阶段，你将直接开始面向真实机器人进行设计。在这个项目中，你会设计一个 Swerve（舵轮）底盘，并学习一种会应用到后续所有项目中的设计工作流程。

1. 学习自顶向下设计和布局草图的基础
2. 使用 COTS（现成商业零件）Swerve 模块建模一个舵轮底盘
3. 创建顶层装配体，并插入一个预先建模好的机构（1678 队 2023 年的升降机构和操控机构）

即使你以前已经建模过底盘，本指南仍然是学习**自顶向下**布局草图设计方法的优秀入门。
