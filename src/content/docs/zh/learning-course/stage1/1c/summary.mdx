恭喜你完成阶段 1C！继续保持！

下面快速总结一下你在 1C 中学习和完成的内容：

* 为各种小型机构使用布局草图
* 使用 Origin Cube 保持一致原点
* 使用可配置零部件，包括 Configurable Rollers 文档和 Configurable Spacer Stack
* 使用 COTS（现成商业零件）零部件，例如管塞、螺母条、伸缩轴承块和 REV MAXPlanetary 齿轮箱
* 理解活轴滚轮和死轴滚轮的区别，以及如何使用它们
* 用电机驱动机构的多种方式
* 使用 3D 打印带轮、隔套、防压块和防压板
* 使用剖视图、从动尺寸、干涉检查、隔离、隐藏和设为透明等工具

使用键盘快捷键可以显著加快你的 CAD（计算机辅助设计）工作流程。请注意遵循最佳实践，避免养成坏习惯。

记住，练习非常重要。你创建的 CAD 模型越多，就会越熟练、越高效。正如 1C 介绍中提到的，如果你觉得还需要更多练习，可以尝试建模更多自己选择的小型机构，并确保向队内更有经验的队员/导师，或 [Discord 服务器](https://discord.gg/frcdesign) 获取反馈。

在阶段 1D 中，你将开始学习自顶向下机器人建模的工作流程，并开始为阶段 1 的最后一个项目建模一个底盘。
